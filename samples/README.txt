Example files to open in GuitarCraft (File > Open).

Morning Walk.gp             The demo song as a Guitar Pro file (the format Guitar Pro 8 opens).
Morning Walk.musicxml       The demo song as MusicXML. Guitar Pro 8 and other notation
                            programs import it.
Morning Walk chart.gcx      A chord chart (made-up words). Chord charts are saved only as
                            .gcx files, never as Guitar Pro files.

The first two are exported from the demo song, and can be made again with:
    guitarcraft --convert demo "samples/Morning Walk.gp"
    guitarcraft --convert demo "samples/Morning Walk.musicxml"

Files the tests use (saved by Guitar Pro 8) are in tests/fixtures/.
